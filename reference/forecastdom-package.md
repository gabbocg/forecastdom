# forecastdom: Conditional and Unconditional Forecast Dominance Testing

Tools for testing conditional superior predictive ability (CSPA) of
forecasting methods with respect to a benchmark, based on Li, Liao, and
Quaedvlieg (2022)
[doi:10.1093/restud/rdab056](https://doi.org/10.1093/restud/rdab056) .
Implements the CSPA test using series-based nonparametric estimation
with Legendre polynomials, Newey-West and pre-whitened HAC covariance
estimation, and adaptive inequality selection.
